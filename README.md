# 🎭 Deep Face Full Analyzer & Liveness Checker

An easy-to-use AI application that analyzes facial features in real-time. This project uses the **DeepFace** framework and **Streamlit** to provide a professional-grade facial analysis dashboard.

## 🌟 Key Features
*   **Emotion Detection:** Recognizes feelings like Happy, Sad, Angry, Surprise, etc.
*   **Demographic Analysis:** Estimates Age, Gender, and Race.
*   **Liveness Detection:** Uses Anti-Spoofing technology to verify if the subject is a real person.
*   **Multi-Input Support:** 
    *   📷 **Image Upload:** Analyze static photos.
    *   📹 **Video Upload:** Process recorded video files.
    *   🎥 **Live Webcam:** Real-time tracking and analysis with visual overlays.

## 🛠️ Built With
*   **Python:** The core programming language.
*   **Streamlit:** For the interactive web interface.
*   **DeepFace:** A lightweight face recognition and facial attribute analysis library.
*   **OpenCV:** For image processing and webcam handling.
