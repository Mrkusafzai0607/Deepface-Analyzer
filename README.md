# 🎭 Deep Face Full Analyzer & Liveness Checker

An interactive AI application that analyzes facial features in real-time. This project uses the **DeepFace** framework and **Streamlit** to provide a professional-grade facial analysis dashboard.

## 🌟 Key Features
*   **Emotion Detection:** Recognizes feelings like Happy, Sad, Angry, etc.
*   **Demographic Analysis:** Estimates Age, Gender, and Race.
*   **Liveness Detection:** Uses Anti-Spoofing technology to verify if the subject is a real person.
*   **Multi-Input Support:** Image Upload, Video Upload, and Live Webcam.

## 🛠️ Built With
*   **Python**, **Streamlit**, **DeepFace**, and **OpenCV**.
